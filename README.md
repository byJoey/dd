

# 🧰 VPS 系统重装助手（交互菜单版）

本项目基于 [bin456789/reinstall](https://github.com/bin456789/reinstall) 脚本，封装了一个美观、易用的 **数字交互菜单**，用于快速选择并重装 VPS 系统。

> 💡 支持 Ubuntu、Debian、CentOS、Alpine、Fedora、OpenEuler 等主流发行版，自动获取最新支持版本，简洁高效！

---

## 📦 功能特点

* ✅ 自动下载最新版 `reinstall.sh`
* ✅ 实时提取支持的系统名称与版本
* ✅ 二级菜单交互式选择（系统 → 版本）
* ✅ 排除特殊系统类型（如 Windows、DD）
* ✅ 彩色输出，美观清晰
* ✅ 直接执行系统重装命令

---

## 🚀 使用方法


### 1. 运行脚本

```bash
bash <(curl -l -s https://raw.githubusercontent.com/byJoey/dd/refs/heads/main/dd.sh)
```
